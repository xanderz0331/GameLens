# GameLens · 屏幕上的英文，随叫随到的中文

> **这是一个廉价小工具。**
> 免费、开源、两千多行 Swift，没有花哨的东西。它只解决一件事：
> **看懂屏幕上的英文，但别马上告诉你。**
>
> 它有几个明确的短板（独占全屏不支持、免费翻译通道质量一般、没做公证），
> 请先看 [已知限制](#八已知限制) 再决定要不要用。

**玩全英文游戏、看美剧、刷英文视频时用的「偷看型」翻译悬浮窗。**

框住屏幕上一小块文字区域，新台词一出现，中文译文就浮在它下方。
按一下快捷键，译文**瞬间消失** —— 先自己读英文，卡住了再瞄一眼。

- 原生 Swift + AppKit，无第三方依赖
- 鼠标穿透，不抢焦点、不挡操作
- 全局快捷键（默认 `⌥ T`）一键隐身
- 支持 Apple 离线翻译，不联网也能用
- 自动把台词记成 Markdown，方便事后复习

## 用在哪

| 场景 | 效果 |
| --- | --- |
| 🎮 **全英文游戏** | 剧情对话、字幕、物品描述，看不懂时按一下快捷键 |
| 🎬 **美剧 / 英剧** | 生肉或英文字幕看不明白，译文浮在字幕下方 |
| 🎥 **英文视频 / 网课** | YouTube、纪录片、访谈，随时查一句 |

> 只识别**屏幕上的文字**，不识别语音。所以需要画面上有字幕或文字。

## 跟别的屏幕翻译有什么不一样

大部分截图翻译工具是「按一下 → 弹窗 → 关掉」，打断节奏；字幕插件则是常驻双语，永远替你翻译，练不到英语。

GameLens 的重点是 **「已经算好了，但先不给你看」**：
译文在后台实时准备好，你按快捷键的那一刻零延迟显示。所以你可以**先自己读，读不懂再秒看**。

## 一、安装

### 方式一：直接下载（推荐，不用编译）

去 [Releases](https://github.com/xanderz0331/GameLens/releases/latest) 下载 **GameLens.app.zip**：

1. 解压，把 `GameLens.app` 拖进「应用程序」
2. **右键 → 打开**（未做 Apple 公证，首次必须这样绕过 Gatekeeper）
3. 系统要求「屏幕录制」权限 → 勾选 GameLens → **退出 App 再重开**
4. 菜单栏出现对话气泡图标，点它 → 框选字幕区域

> 别人拿到 zip 就能用，不需要 Xcode、不需要编译。

### 方式二：从源码编译

**一步到位**（编译 + 装到 /Applications + 启动）：

```bash
./install.sh
```

或者只编译，自己拖进「应用程序」：

```bash
./build.sh          # 产物：dist/GameLens.app
```

> 首次打开如果提示「无法验证开发者」，在「访达」里右键 → 打开。
>
> 注意：屏幕录制权限绑定 App 所在路径，**建议先装进 /Applications 再授权**，
> 否则从别处授权后一移动 App，权限就失效了。

## 二、第一次使用

1. 启动后**屏幕右上角的菜单栏**会出现一个「对话气泡」样式的图标（没有 Dock 图标，它常驻菜单栏）。
2. 系统要求「屏幕录制」权限 → 系统设置 › 隐私与安全性 › 屏幕录制 → 勾选 **GameLens** → 回到对话框点「已授权，重新检查」。
   - 勾选后仍提示没权限，就**退出再重开一次**。
3. 点菜单栏那个图标 → **框选识别区域…** → 用鼠标拖出一个框，**只框住出现文字的那一小块**。
4. 文字一出现，译文就会浮在它下方。

## 三、练英语的三种强度

默认快捷键 **`⌥ T`** 隐藏 / 显示译文。

| 模式 | 设置 | 效果 |
| --- | --- | --- |
| 纯辅助 | 一直显示 | 全程双语，像看双语字幕 |
| **先猜后看** | 手动按 `⌥ T` | 默认藏着，卡住才按一下 |
| **限时偷看** | 设置里「自动隐藏」= 5 秒 | 按一下看 5 秒自动消失，逼自己继续读 |

第三种最适合练阅读：英文出现 → 自己读 → 不确定就偷看 → 5 秒后消失。

快捷键可在设置里换成 `⌃⌥T`、`⌥D`、`⌥Space`、`⌃⌥F` 或 `F2`。

## 四、看美剧 / 视频怎么用

1. 用**本地播放器**（IINA、VLC、MPV）或网页播放器，让字幕显示在画面上。
2. 框选**字幕那一行**，不用框整个画面。
3. 按 `⌥ T` 控制译文显示。

⚠️ **DRM 限制**：Netflix、Apple TV+、Disney+ 这类带版权保护的流媒体，系统层面就禁止截取画面，
抓到的是**黑屏**——这是 macOS 的限制，所有录屏/截图工具都一样，不是本 App 的 bug。
B 站、YouTube、本地视频文件一般没有这个问题。

> 小技巧：把播放器窗口化，框选区域只罩住字幕，识别又快又准。

## 五、翻译引擎怎么选

点菜单栏图标 → 「设置…」→ 引擎。

| 引擎 | 需要联网 | 说明 |
| --- | --- | --- |
| **自动（推荐）** | 视情况 | 优先 Apple 离线，不可用时自动退到 Google |
| **Apple 离线翻译** | ❌ | 完全本地，最省心。需系统先下载语言包 |
| **Google 网页翻译** | ✅ | 免密钥，部分网络环境可能连不上 |
| **DeepL** | ✅ | 质量好，需要填 API Key |
| **自定义 API** | ✅ | 任何 OpenAI 兼容接口（DeepSeek / Kimi / OpenRouter / 本地 Ollama） |

### 安装 Apple 离线语言包

第一次用会提示「语言包未安装」。打开 Mac 自带的 **「翻译」App**，
翻译一句英文 → 中文，语言包就下载好了，全系统共享，之后 GameLens 可以完全离线用。

### 用 DeepSeek 之类的大模型

设置里选「自定义 API」，填：

- Base URL：`https://api.deepseek.com/v1`
- API Key：你的 key
- 模型名：`deepseek-chat`

勾上「AI 讲解生词 / 俚语」后，译文下面会多一行 `▸` 开头的讲解（比如短语动词的意思）。
这是普通翻译 API 给不了的东西。

## 六、暂停与退出 ⭐

这是菜单栏 App，**没有 Dock 图标**，所以别去程序坞里找。所有操作都在**屏幕右上角菜单栏**那个「对话气泡」图标里（图标在系统设置里被折叠时，按 `⌘` 拖动可以调整位置）。

### 三种状态

| 你想做什么 | 怎么做 | 结果 |
| --- | --- | --- |
| 暂时不翻译，一会儿还用 | 点菜单栏图标 → **暂停识别（停止抓屏）** | 立刻停止抓屏和 OCR，CPU 归零，悬浮窗收起，图标变成 ⏸ |
| 今天不用了 | 点菜单栏图标 → **退出 GameLens（彻底关闭）** | 进程结束，菜单栏图标消失，悬浮窗消失 |
| 图标没了 / 程序卡住 | `⌘⌥Esc` → 活动监视器 → 搜 `GameLens` → 点 ⨯ | 强制结束 |

### 快捷键总表

| 快捷键 | 作用 |
| --- | --- |
| `⌥T` | 隐藏 / 显示译文（可在设置里改） |
| `⌃⌥Q` | **退出 GameLens** |

### 需要知道的几点

- ✅ **不会开机自启**。没有安装任何 LaunchAgent、登录项或后台代理。你不启动它，它就完全不存在。
- ✅ **退出后不占任何资源**，也不再抓屏。
- ⚠️ **「暂停」和「退出」的区别**：暂停只是停止工作，进程还在（菜单栏图标还在），下次点「继续识别」立刻恢复；退出是整个进程结束。
- ⚠️ 退出**不会**清除「屏幕录制」授权。这个授权存在系统设置里，下次打开直接可用，不会重复问你。
- 💡 想彻底删干净，见下面的「卸载」。
- 🔁 **重复打开不会开出两个**：新实例会自动把旧实例关掉（v1.0.1 起）。

## 七、其他设置

- **字号 / 背景不透明度**：字幕大小和底色深浅
- **同时显示英文原文**：把识别到的英文行也显示在译文上方
- **刷新间隔**：默认 0.4 秒。越小越跟手，CPU 越高；0.3~0.6 比较合适
- **保存台词到 Markdown**：写入 `~/Documents/GameLens/对话记录.md`

## 八、已知限制

**这些是硬限制，不是 bug，买之前先看清楚：**

| # | 限制 | 影响 |
| --- | --- | --- |
| 1 | **独占全屏的游戏会盖住悬浮窗** | 必须用「窗口」或「无边框窗口」模式。macOS 原生全屏（视频播放器/浏览器）一般没问题 |
| 2 | **只识别画面文字，不识别语音** | 游戏/剧集必须有字幕或文字 |
| 3 | **DRM 流媒体抓到黑屏** | Netflix、Apple TV+ 等，macOS 系统限制，所有录屏工具一样 |
| 4 | **免费翻译通道质量一般** | 内置 MyMemory 是翻译记忆库，会出「Vou 认为…」这种鬼东西。想要好效果请自备 API Key |
| 5 | **没做 Apple 公证** | 首次打开要右键 → 打开 |
| 6 | 竖排文字、艺术字体、快速滚动字幕识别率下降 | — |
| 7 | 框选区域越大会越慢 | 只框字幕那一条最好 |

## 九、隐私

- 截图只在内存里做 OCR，**不落盘、不上传**。
- 选了在线翻译引擎时，只有识别出来的**文字**会发给你选的翻译服务。
- 记录文件只写在你自己电脑的 `~/Documents/GameLens/`。第一次写入时系统可能问
  「GameLens 想要访问你的「文稿」文件夹」，允许即可；不想被问就在设置里关掉「保存台词」。

## 十、卸载

1. 点菜单栏图标 → **退出 GameLens**
2. 从「应用程序」里把 `GameLens.app` 拖到废纸篓

彻底清理残留：

```bash
rm -rf ~/Documents/GameLens          # 台词记录
defaults delete com.local.gamelens   # 设置项
```

如果还想删掉系统里的屏幕录制授权：系统设置 › 隐私与安全性 › 屏幕录制 → 选中 GameLens → 点 `–`。

## 十一、改 Bundle ID（二次分发前）

`Info.plist` 和 `build.sh` 里的 `com.local.gamelens` 换成你自己的，例如 `com.你的名字.gamelens`，
然后重新 `./build.sh`。

> 改完必须重新授权屏幕录制：系统设置里先点 `–` 删掉旧条目，再重新添加新版本。

## 技术实现

- 抓屏：`ScreenCaptureKit` 的 `SCScreenshotManager`，只抓框选的一小块（省电）
- OCR：`Vision` 的 `VNRecognizeTextRequest`（accurate 模式）
- 翻译：`Translation` 框架（系统离线）/ Google / DeepL / 任意 OpenAI 兼容接口
- 悬浮窗：`NSPanel` + `CGWindowLevelForKey(.screenSaverWindow)`，鼠标穿透、跨 Space、覆盖全屏 App
- 快捷键：Carbon `RegisterEventHotKey`（不需要辅助功能权限，也不会吞掉输入法按键）
- 判重：连续两次 OCR 结果一致才认为是新台词，规避打字机效果和淡入动画的抖动
