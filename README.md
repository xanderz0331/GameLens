# GameLens · 游戏台词实时翻译（macOS）

[English](README.en.md) · 中文

玩游戏练英语用的小工具：**只在屏幕上框一小块台词区域**，台词一变，中文译文就浮在台词框下方；
按一下快捷键就能**瞬间把译文藏起来**，先自己读英文，卡住了再瞄一眼。

- 原生 Swift + AppKit，没有第三方依赖，不联网也能用（配合 Apple 离线翻译）
- 鼠标穿透的悬浮窗，不抢游戏焦点、不挡操作
- 全局快捷键（默认 `⌥ T`）一键隐藏 / 显示
- 自动记录台词到 Markdown，方便事后复习

## 一、安装

**一步到位**（编译 + 装到 /Applications + 启动）：

```bash
cd GameLens
./install.sh
```

或者只编译，自己拖进「应用程序」：

```bash
./build.sh          # 产物：dist/GameLens.app
```

> 首次打开如果提示「无法验证开发者」，在「访达」里右键 → 打开。
>
> 注意：屏幕录制权限是绑定到 App 所在路径的，**建议先装进 /Applications 再授权**，
> 否则从别处授权后一移动 App，权限就失效了。

## 二、第一次使用

1. 启动 GameLens，菜单栏出现一个 💬 图标（没有 Dock 图标，它是菜单栏 App）。
2. 系统会要求「屏幕录制」权限 → 打开系统设置 → 隐私与安全性 → 屏幕录制 → 勾选 **GameLens** → 回到对话框点「已授权，重新检查」。
   - 如果勾选后仍提示没权限，**退出 GameLens 再重新打开**。
3. 点「开始框选区域」，用鼠标拖出一个框，**只框住游戏里出现台词的那一小块**（不用框整个屏幕）。
4. 进游戏，台词一出现，译文就会浮在台词框下方。

## 三、核心玩法：偷看模式

默认快捷键 **`⌥ T`** 隐藏 / 显示译文。

三种推荐用法，按练习强度递增：

| 模式 | 设置 | 效果 |
| --- | --- | --- |
| 辅助阅读 | 一直显示 | 全程双语，像看双语字幕 |
| **先猜后看** | 手动按 `⌥ T` | 默认藏着，卡住才按一下 |
| **限时偷看** | 设置里「自动隐藏」设成 5 秒 | 按一下看 5 秒，自动消失，逼自己继续读英文 |

第三种最适合练阅读：英文台词出现 → 自己读 → 不确定就按快捷键偷看 → 5 秒后消失。

快捷键可以在设置里换成 `⌃⌥T`、`⌥D`、`⌥Space`、`⌃⌥F` 或 `F2`。

## 四、翻译引擎怎么选

菜单栏图标 → 「设置…」→ 引擎。

| 引擎 | 是否需要联网 | 说明 |
| --- | --- | --- |
| **自动（推荐）** | 视情况 | 优先用 Apple 离线翻译，不可用时自动退到 Google |
| **Apple 离线翻译** | 否 | 完全本地，最省心。需要系统先下载语言包 |
| **Google 网页翻译** | 是 | 免密钥，国内网络可能连不上 |
| **DeepL** | 是 | 质量好，需要填 API Key |
| **自定义 API** | 是 | 任何 OpenAI 兼容接口（DeepSeek / Kimi / OpenRouter / 本地 Ollama） |

### 安装 Apple 离线语言包

第一次用 Apple 离线翻译会提示「语言包未安装」。打开 Mac 自带的 **「翻译」App**，
翻译一句英文 → 中文，语言包就会下载并全系统共享，之后 GameLens 就能离线用了。

### 用 DeepSeek 之类的大模型

设置里选「自定义 API」，填：

- Base URL：`https://api.deepseek.com/v1`
- API Key：你的 key
- 模型名：`deepseek-chat`

勾上「AI 讲解生词 / 俚语」后，译文下面还会多一行「▸」开头的简要讲解（比如 phrasal verb 的意思）。
这是用大模型当翻译引擎的好处 —— 普通翻译 API 给不了。

## 五、其他设置

- **字号 / 背景不透明度**：字幕大小和底色深浅
- **同时显示英文原文**：把识别到的英文行也显示在译文上方
- **刷新间隔**：默认 0.4 秒。越小越跟手，CPU 越高；0.3~0.6 比较合适
- **保存台词到 Markdown**：写入 `~/Documents/GameLens/对话记录.md`

## 六、已知限制（重要）

1. **独占全屏（Exclusive Fullscreen）下悬浮窗会被游戏盖住。**
   请把游戏改成「窗口」或「无边框窗口 / Borderless」模式。绝大多数游戏在设置里都有这个选项。
2. **只识别画面上的文字，不识别语音。** 所以游戏需要有台词字幕（大部分剧情向游戏都有）。
3. 港漫 / 竖排文字、艺术字体、快速滚动的字幕识别率会下降。
4. 框选区域太大会拖慢识别速度，**只框台词框**最好。

## 七、隐私

- 截图只在内存里做 OCR，**不落盘、不上传**（除非你选了在线翻译引擎，那时只有识别出来的**文字**会发给你选的翻译服务）。
- 记录文件只写在你自己电脑的 `~/Documents/GameLens/`。第一次写入时系统可能会问
  「GameLens 想要访问你的「文稿」文件夹」，允许即可；不想被问就在设置里关掉「保存台词」。

## 八、改 Bundle ID（二次分发前）

`Info.plist` 和 `build.sh` 里的 `com.local.gamelens` 换成你自己的，例如 `com.你的名字.gamelens`，
然后重新 `./build.sh`。

> 改完必须重新授权屏幕录制：系统设置里先减号删掉旧条目，再重新添加新版本的 GameLens。

## 九、卸载

菜单栏「退出 GameLens」→ 删除 `GameLens.app`。
如需彻底清理：`rm -rf ~/Documents/GameLens`，以及删掉 `defaults delete com.local.gamelens`。

### 技术实现

- 抓屏：`ScreenCaptureKit` 的 `SCScreenshotManager`，只抓框选的一小块（省电）
- OCR：`Vision` 的 `VNRecognizeTextRequest`（accurate 模式）
- 翻译：`Translation` 框架（系统离线）/ Google / DeepL / 任意 OpenAI 兼容接口
- 悬浮窗：`NSPanel` + `CGWindowLevelForKey(.screenSaverWindow)`，鼠标穿透、跨 Space、覆盖全屏 App
- 快捷键：Carbon `RegisterEventHotKey`（不需要辅助功能权限，也不会吞掉输入法按键）
- 换行判重：连续两次 OCR 结果一致才认为是「新台词」，规避打字机效果和淡入动画的抖动
